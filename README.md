The source of my personal portfolio, live at **[janicewillafrancisco.com](https://www.janicewillafrancisco.com)**.

## How it's built

- Hand-built **single-page HTML, CSS and JavaScript**, with no framework and no build step
- Responsive from 360px phones up to wide desktop screens, with mobile-specific layouts
- Optimized **WebP images** with responsive `srcset`, non-blocking web fonts and lazy loading
- Accessible: semantic markup, keyboard focus states and reduced-motion support
- SEO-ready: meta and Open Graph tags, JSON-LD structured data, sitemap and robots.txt
- Contact form powered by **Web3Forms**
- Hosted on **Vercel** with Web Analytics and Speed Insights

**Lighthouse:** 100 Accessibility · 100 SEO · 98–100 Performance on desktop
